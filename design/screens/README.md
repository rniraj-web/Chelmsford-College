# Screen exports (add these from Figma by hand)

Claude Code uses these PNGs as visual references. Exporting by hand in Figma doesn't use the MCP allowance.

**How to export:**
1. Open the link.
2. Select the frame or section.
3. In the right panel, go to **Export**, add **PNG at 2x**, and click Export.
4. Save into this folder using the file name below.
